Why this exists

Plate-solving tells you what’s there. It doesn’t make it presentable.

Siril can already tell you that a frame contains M31, NGC 206, and M110 — but that information lives in a dialog, not in the image you actually want to share. Getting from “plate-solved” to “labeled and ready to post” usually means exporting into another editor and placing text boxes by hand, one image at a time, starting over every session.

DG Modern Annotator skips that detour. It runs from Siril’s own Scripts menu, reads the same WCS solution Siril already computed, and gives you a real interactive canvas — drag labels where you want them, style markers per catalog, add a coordinate grid or compass, and export at full resolution. Set your style once; every image after starts from where you left off.

“Built for the plate-solved image you already have — not a general graphics tool taught to understand astronomy.”
6 catalogs searched automatically — Messier, NGC, IC, Sharpless, LDN, and bright stars, each with its own color.
4 export formats at true native resolution — JPEG, PNG, 8-bit TIFF, 16-bit TIFF.
0 manual installs — every dependency sets itself up inside Siril the first time you run it.
What it does

Everything a labeled image needs, in one canvas.

Each marker color below is the same one you’ll see on your own image — the app assigns a color per catalog, and this page borrows it.

Automatic detection

Every Messier, NGC, IC, Sharpless, LDN, and bright star in frame, found automatically — VizieR online, Siril’s own bundled catalogs offline.

Drag anything

Markers and labels move independently. Auto Arrange keeps new labels out of each other’s way; Reset Position undoes a single drag without touching the rest.

Shapes that fit

Circles for point sources, brackets for clusters, and a rotatable ellipse for galaxies that were never round to begin with.

Style once, reuse always

Per-catalog colors, typography, and marker style save as a preset and carry into your next image — nothing to re-decide session to session.

Sky context, if you want it

An RA/Dec coordinate grid, a compass, and a technical-details panel pulled straight from the FITS header — all optional, all draggable, off by default.

Full-resolution export

JPEG, PNG, 8-bit or 16-bit TIFF, at the image’s true native resolution — independent of whatever you’re previewing on screen.

Overlays

Sky context, when you want it.

All three are off by default and turn on with one click from the toolbar — each is fully draggable and stays out of your way otherwise.

RA/Dec grid

A coordinate grid computed from your image’s own WCS solution, labeled in sexagesimal — spacing picks itself based on field of view.

Compass

North/East direction arrows, derived from the actual plate solve — correct even when the field is rotated or mirrored.

Info box

Camera, telescope, filter, exposure — pre-filled from the FITS header and freely editable, positioned at any corner.

Get started

Two steps, then it’s in your Scripts menu.

Download the script, drop it into Siril’s scripts folder, relaunch. Everything else — PyQt6, astropy, astroquery — installs itself into Siril’s own Python environment the first time you run it.
